# Original Online Cafe

We're a small team of friends who share the same passion: making games.

Right now we're indie developers, learning by building, and finishing one game at a time. Our dream is to grow into a real studio someday, and if the chance comes, make the kind of big, ambitious games we grew up playing.

Each game has its own repo with the full details.
